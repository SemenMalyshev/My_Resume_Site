Как устроен проект

Игры и веб-платформа — отдельные части проекта со своим стеком.

Unity / C#SvelteKit / TypeScriptNode.jsHTTP / WebSocket / WSSPostgreSQL / Drizzle
  1. Общий экран

    Unity WebGL запускает игру в браузере. Игровая логика и механики находятся в Unity-проектах.

  2. Смартфоны игроков

    Браузерные контроллеры передают действия игроков; WebSocket связывает участников с общей игрой.

  3. Веб-платформа и сервер

    SvelteKit и Node.js обслуживают страницы, HTTP API и WebSocket-соединения. nginx обеспечивает HTTPS/WSS.

  4. Данные платформы

    PostgreSQL и Drizzle используются для данных пользователей и сессий. Игры публикуются как отдельные WebGL-сборки.

Результат — выпущенные игры и единая платформа для запуска и подключения игроков.
