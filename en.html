How the project works

The games and the web platform are separate parts of the project, with different technology stacks.

Unity / C#SvelteKit / TypeScriptNode.jsHTTP / WebSocket / WSSPostgreSQL / Drizzle
  1. Shared screen

    Unity WebGL runs the game in the browser. Gameplay logic and mechanics live in the Unity projects.

  2. Players’ phones

    Browser-based controllers send player input; WebSocket connects participants to the shared game.

  3. Web platform and server

    SvelteKit and Node.js serve pages, HTTP APIs and WebSocket connections. nginx handles HTTPS/WSS.

  4. Platform data

    PostgreSQL and Drizzle store user and session data. Games are published as separate WebGL builds.

The result is a released game catalog and a shared platform for launching games and connecting players.
